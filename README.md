# 面試官實習生 The Interviewer Intern

給面試官練習結構化面試的單機網頁遊戲。玩家扮演實習面試官，在 30 分鐘內用提問卡面試隨機出現的候選人，結束後替候選人的職能評分並給出錄取建議，系統再依提問技巧給出等第、五面向分數與改善建議。

- 純靜態網頁：不需要後端、不需要 API 金鑰、不連線任何語言模型。
- 人物動畫用 p5.js（從 CDN 載入）。離線、CDN 被擋或系統開啟「減少動態效果」時不播 p5 動畫，遊戲照常可玩。
- 候選人的回答用瀏覽器內建語音朗讀（Web Speech API），依候選人性別自動挑男聲或女聲；裝置沒有中文語音時只顯示文字。
- 進度只存在瀏覽器的 localStorage（星數、實戰模式、語音設定），清除瀏覽器資料就會重置。
- 製作者：黃政文｜360d才庫事業群

## 怎麼玩

1. 首頁按「實習關卡」選產業與職缺，或按「隨機面試」直接抽一位候選人。
2. 面試前準備頁會列出 JD 與要評估的職能，可以按「換一位候選人」重抽。
3. 面試中從下方題卡出題。每題會花掉時間，候選人的放鬆度、意願度會隨問法變化。
4. 候選人回答含糊時，用「追問深挖」卡挖出具體角色、結果與反思，有機會觸發「發掘潛力」或「看穿真相」。
5. 時間用完、候選人離席或自己按「結束面試」後，替每項職能評 0 到 3 分並選擇錄取建議。
6. 報告會給出等第（S、A、B、C、D）、五面向分數、法律合規性檢測、提問技巧分析、判斷對照與具體改善建議。報告可用瀏覽器列印存成 PDF。

面試前準備頁的「實戰模式」開啟後，面試中不顯示教練筆記、法規提醒與風險計數，回饋全部留到報告與逐字稿裡。

手機上（700px 以下）時間、放鬆度、意願度與候選人的話固定在畫面上方，題卡只顯示類型，點類型才從下方彈出題目，出題後題目面板收起，直接看到候選人回答。

### 語音設定

首頁「🔊 語音設定」或面試畫面右上角 🔊 開啟。可以：

- 開關朗讀（🔇 表示已關閉）。
- 分別指定女性候選人、男性候選人用哪個聲音，按「▶ 試聽」聽範例句。選「自動」時依候選人立繪判斷性別，台灣中文優先、本機語音優先；沒有男聲時用女聲降低音調。
- 調整語速（0.5 到 1.5 倍）。
- 新安裝語音後按「↻ 重新偵測」。Windows 在「設定 > 時間與語言 > 語音」新增「中文（台灣）」；iPhone 在「設定 > 輔助使用 > 朗讀內容 > 聲音 > 中文」下載。

設定存在這台裝置的瀏覽器，換裝置或清除瀏覽器資料要重設。指定的聲音在別台裝置不存在時，自動改回「自動」。

## 本機執行

直接用瀏覽器開啟 `index.html` 即可（file:// 可正常運作）。

想用本機伺服器測試時：

```bash
python -m http.server 8765
```

再開啟 http://127.0.0.1:8765/ 。

## 上架 GitHub Pages

1. 把整個 `TheInterviewerIntern` 資料夾放進一個 GitHub repository 的根目錄（index.html 要在 repository 根目錄）。
2. `360d才庫-面試對練助理/` 是 v1 參考版，已列在 `.gitignore`，不會被上傳。它的提示詞內含政黨等敏感題目範例，建議不要公開。
3. 保留根目錄的 `.nojekyll`，避免 GitHub Pages 用 Jekyll 處理檔案。
4. 到 repository 的 Settings → Pages，Source 選「Deploy from a branch」，Branch 選 `main`、資料夾選 `/ (root)`，儲存。
5. 幾分鐘後網址會出現在同一頁，格式為 `https://<帳號>.github.io/<repository 名稱>/`。

所有路徑都是相對路徑，放在子路徑底下也能運作。字型從 Google Fonts 載入，離線時會退回系統字型。p5.js 1.11.1 由 `js/fx.js` 從 jsDelivr 載入，網址寫在該檔的 `P5_URL`；想完全離線時可下載同版本 `p5.min.js` 放進專案，再把 `P5_URL` 改成相對路徑。

## 專案結構

```
index.html              入口，依序載入資料與程式
css/                    base（共用、首頁、關卡）、interview（面試畫面）、report（評分與報告、列印）
js/
  engine.js             面試規則：純函式，回傳新 session 與事件
  scoring.js            評分、法律合規性檢測、提問技巧分析、建議
  store.js              localStorage 進度與偏好
  fx.js                 p5.js 動畫層（人物呼吸、情緒反應、粒子特效）
  voice.js              朗讀候選人回答（Web Speech API：斷句、依性別挑聲音）
  ui-*.js               各畫面渲染與事件
  main.js               啟動
data/
  common.js             職能、共用題庫、追問卡、法規參考、候選人原型、立繪清單
  industries/<id>.js    產業、面試官、3 個關卡（JD、職能、專屬題目，部分含 3 位候選人）
  cands/<id>-<n>.js     各關卡追加的候選人
assets/                 ComfyUI 產生的背景與立繪（webp）
docs/content-spec.md    候選人資料格式與撰寫規範
tests/                  內容驗證、引擎模擬與語音挑選測試（Node.js）
GDD.md                  遊戲設計文件
GAPS.md                 已知限制與待補項目
dev-log.md              開發紀錄
```

## 新增或修改內容

候選人資料格式與撰寫規範見 `docs/content-spec.md`。修改後執行：

```bash
node tests/validate.js
```

```bash
node tests/engine.test.js
```

兩者都顯示 0 個錯誤、0 個失敗才算通過。`validate.js` 檢查欄位、引用與文字規則；`engine.test.js` 對每位候選人模擬面試，確認每個特質都挖得到、好面試分數高於壞面試、同一個 seed 結果可重現。

修改 `js/voice.js`（朗讀斷句、挑聲音）後執行：

```bash
node tests/voice.test.js
```

新增產業時，在 `data/industries/` 新增檔案並用 `TII.registerIndustry` 註冊，再到 `index.html` 加上對應的 `<script>`。新增候選人檔用 `TII.addCandidates('<關卡 id>', [...])`，同樣要加進 `index.html`，且必須放在產業檔之後。
